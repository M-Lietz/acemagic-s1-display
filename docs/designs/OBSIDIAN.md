# Obsidian

Status: implementiert und auf einem echten AceMagic S1 unter Proxmox-LXC live geprüft

Obsidian ist die materialbetonte, nahezu monochrome Alternative. CPU und RAM
stehen als große typografische Werte in einer Split-Ansicht; der Zustand bildet
einen eigenständigen ruhigen Block.

- Renderer-ID: `obsidian`
- Theme: `s1panel/themes/obsidian/obsidian.json`
- Vorschau: `s1panel/designs/previews/obsidian.png`
- Hauptlayout: zweigeteilte Typografie mit zentralem Gesundheitsstatus
- Akzente: Graphit, Stahlgrau und ausschließlich funktionale Statusfarben
- Bewegung: kurze Wertinterpolation, keine verspielten Effekte
- Zustände: vollständige Online-, Warning-, Offline- und N/A-Darstellung
